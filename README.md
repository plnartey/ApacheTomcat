# cloud-ci-lab-project

A simple Python application built as part of a Cloud CI/CD lab project.

## Description

This app demonstrates a basic Cloud CI Pipeline setup using Python.

## Requirements

- Python 3.x

## How to Run

```bash
python app.py
```

## Expected Output

```
Cloud CI Pipeline Running
```
